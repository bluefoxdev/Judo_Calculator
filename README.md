### Judo Calculator



The judo calculator is a University project for a made up judo gym company, used to calculate the cost to the athletes for the chosen gym plans (subscriptions) as well as putting the athlete into a correct weight class.





When the project began the program was given the following requirements to follow:



* cater to the above project requirements
* have no branching if statements 
* use OOP (Object Oriented Programming)
* demonstrate inheritance 
* feature at least one pure function
